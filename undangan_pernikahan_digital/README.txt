UNDANGAN PERNIKAHAN DIGITAL - DENGAN MUSIK

File:
- index.html: struktur halaman undangan dan elemen audio
- style.css: tampilan dan desain
- script.js: interaksi tombol dan kontrol musik
- Sp_decoration_sukorejo_mp3.mp3: lagu yang kamu unggah

Cara menjalankan:
1. Ekstrak ZIP.
2. Simpan semua file dalam satu folder (jangan pisahkan file MP3).
3. Buka index.html di browser.
4. Klik Buka Undangan. Lagu akan mulai diputar jika browser mengizinkan.
5. Gunakan tombol musik di kanan bawah untuk jeda atau memutar kembali.

Catatan:
- Lagu diputar dari file MP3 lokal, jadi tidak perlu URL musik dari internet.
- Bootstrap CSS/JS dan foto latar online masih membutuhkan internet.
- Nama, tanggal, waktu, dan alamat acara adalah contoh dan bisa diganti di index.html.
- Tombol konfirmasi kehadiran belum menyimpan data ke database.
